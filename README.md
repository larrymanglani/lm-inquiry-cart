# Larry Manglani's Inquiry Cart

[![WordPress Plugin Version](https://img.shields.io/wordpress/plugin/v/lm-inquiry-cart?label=WordPress.org)](https://wordpress.org/plugins/lm-inquiry-cart/)
[![License](https://img.shields.io/github/license/larrymanglani/lm-inquiry-cart)](LICENSE)

Secure WordPress plugin for B2B product inquiries. Let visitors build a cart of items and submit one consolidated inquiry.

## 🚀 Features
- ✅ CSRF-protected with WordPress nonces
- 🍪 Cookie-based cart (no database bloat)
- 📱 Responsive, mobile-friendly UI
- ⚡ Lightweight & caching-plugin compatible

## 📦 Installation
1. Download from [WordPress.org](https://wordpress.org/plugins/lm-inquiry-cart/)
2. Upload to `/wp-content/plugins/`
3. Activate & configure in **Settings → Inquiry Cart**
