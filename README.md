# Larry Manglani's Inquiry Cart

[![License](https://img.shields.io/github/license/larrymanglani/lm-inquiry-cart)](LICENSE)
[![WordPress Tested](https://img.shields.io/wordpress/v/lm-inquiry-cart)](https://wordpress.org/plugins/lm-inquiry-cart/)

**Secure WordPress plugin for B2B product inquiries and lead generation.**

## 🌟 Features

- **Virtual Inquiry Cart**: Let visitors add multiple products and submit one comprehensive inquiry
- **CSRF Protection**: Full WordPress nonce verification for security
- **Cookie-Based**: Lightweight system that doesn't bloat your database
- **Cross-Tab Sync**: Real-time cart updates across browser tabs
- **Simple Shortcodes**: Easy integration with any theme or page builder
- **Mobile Responsive**: Works perfectly on all devices
- **Caching Compatible**: Works with WP Rocket, W3 Total Cache, LiteSpeed, etc.

## 📦 Installation

### From WordPress.org
1. Go to **Plugins → Add New** in your WordPress admin
2. Search for "Larry Manglani's Inquiry Cart"
3. Click **Install Now** then **Activate**

### Manual Installation
1. Download the plugin from [WordPress.org](https://wordpress.org/plugins/lm-inquiry-cart/)
2. Upload the `lm-inquiry-cart` folder to `/wp-content/plugins/`
3. Activate through **Plugins** menu in WordPress
4. Configure settings in **Settings → Inquiry Cart**
